## 2026-08-06
- 사목협의회 직책에 하위 배치 방식(자동·가로·세로·그리드)과 최대 열 수 설정 추가
- 관리자 직책 화면에 배치 설정과 상위 직책 변경용 DnD를 추가하고 공개 조직도를 무라이브러리 반응형 연결 구조도로 변경
- 같은 직책의 여러 구성원을 독립 항목으로 배치하고 직책 묶음 중앙에서 다음 단계 연결선이 이어지도록 개선
- 직책 묶음과 하위 분기의 연결선 접점을 보정하고 이름·세례명을 각각 한 줄로 분리
- 공개 사목협의회 조직도를 외부 그래프 라이브러리 없는 세로 직책 트리로 변경
- 직책별 인원수와 구성원 목록을 표시하고 하위 직책을 들여쓰기 연결선으로 표현
- 구성원 행은 무테·무그림자의 컴팩트 인물 UI를 유지하고 공석인 말단 직책은 제외

## 2026-08-05

- 기존 관리자 이메일의 `@` 앞부분을 아이디로 이전하고 관리자 이메일 컬럼 제거
- 사목협의회 고정 직책 enum을 자기 참조 `PastoralCouncilPosition` 트리와 구성원 배정 구조로 전환
- 사목협의회 관리자 화면에 직책 관리·구성원 관리·공개 미리보기 탭 추가
- 공개 사목협의회 화면을 직책 부모 관계와 노출 순서에 따라 자동 구성하도록 변경

## 2026-07-27
- 일반 관리자에게 사용자별 메뉴 단위 전체 CRUD 권한을 부여하는 `menuPermissions` 모델 추가
- 최고관리자는 전체 메뉴를 유지하고 사용자 등록 메뉴는 권한 상승 방지를 위해 최고관리자 전용으로 유지
- 관리자 사이드바·대시보드·페이지·API에 동일한 권한 규칙을 적용하고 미등록 관리자 경로는 기본 차단
- 사용자 등록 및 권한 설정 화면을 React Hook Form과 shadcn 체크박스 그룹으로 개편

## 2026-07-21
- 관리자 로그인을 이메일·비밀번호 기반 access JWT + 회전형 refresh token 방식으로 전환
- 인증 쿠키를 `HttpOnly`/`SameSite`로 보호하고 관리자 변경 API에 CSRF 검증 추가
- 신규 비밀번호를 scrypt로 저장하고 기존 SHA-256 비밀번호는 로그인 시 자동 승격
- 관리자 로그인 폼을 React Hook Form 검증과 공통 오류·토스트 처리 방식으로 정리
- `Attachment`, `PostImage`, `ContentImageAsset`의 중복 메타데이터를 `FileAsset + PostAsset` 구조로 정규화
- 기존 첨부파일·대표 이미지·본문 이미지 데이터를 역할 기반 사용처로 자동 백필하는 안전한 마이그레이션 추가
- 게시물 저장·수정·삭제 시 실제 파일 사용처를 동기화하고 제거 자산을 MinIO에서 정리
- 24시간 이상 된 미연결 이미지를 삭제하는 보호된 내부 API와 Synology 작업 스케줄러 실행 스크립트 추가
- 신규 구조의 운영 검증과 데이터 대응 검사를 거쳐 레거시 파일 테이블 및 상태 enum 제거
